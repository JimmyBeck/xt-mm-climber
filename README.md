# 🎈 小天媒媒助手 (xt-mm-climber)

> **专为小红书创作者、自媒体运营与数据分析爱好者打造的「安全极简数据采集助手」**  
> 一键导出笔记全文、高清无水印图片/视频、以及展开全部深层评论到 Excel 表格。无需编程，解压即用！

---

## ✨ 为什么选择小天媒媒助手？

市面上的很多采集工具要么需要懂编程部署，要么收费昂贵且动不动就导致账号被风控。**小天媒媒助手专为普通用户设计**：

* 🛡️ **账号绝对安全（零封号风险）**：直接在你的正常浏览器里运行，不偷发危险请求，内置真人慢速防风控机制，绝不伤害你的小红书账号。
* 📝 **100% 完整长文提取**：告别只有前 50 个字的预览摘要，一键拿到完整正文排版。
* 💬 **评论区折叠回复全展开**：自动帮你点击那些被系统折叠的**“展开 X 条回复”**，把深层精彩评论一条不漏全部提出来。
* 🖼️ **无水印原图 & 视频一键打包**：自动去除平台水印与压缩参数，一键打包下载高清原图和 MP4 视频。
* 📊 **自动排版 Excel 报表**：每次导出自动带上精确到秒的时间戳，生成的表格分类清晰、美观大方。

## 🚀 3 步极简安装指引 (小白教程)

无需任何开发基础，跟着下面 3 步即可在电脑上用起来：

### 第一步：下载扩展文件
点击页面右上角的绿色按钮 **`Code` $\rightarrow$ `Download ZIP`** 下载安装包并解压到你的电脑（如桌面）。

*(注：如果你是开发者，也可以直接在项目目录运行 `npm install && npm run build` 生成构建包)*

### 第二步：在浏览器中开启扩展
1. 打开电脑上的 **Google Chrome** 或 **Edge** 浏览器；
2. 在地址栏输入并打开：`chrome://extensions/`；
3. 打开右上角的 **「开发者模式」** 开关；
4. 点击左上角的 **「加载已解压的扩展程序」**；
5. 选中本项目中的构建目录文件夹（`.output/chrome-mv3`）。

### 第三步：打开小红书开始体验
1. 在浏览器中打开 [小红书网页版](https://www.xiaohongshu.com/explore)；
2. 页面右侧中间会出现一个红色的 **「小天媒媒助手」** 胶囊挂件；
3. 点击挂件展开面板，即可开始你的数据采集与素材导出！

## ❓ 常见问题答疑 (FAQ)

**Q：采集速度为什么不是一瞬间完成？**  
A：为了绝对保护你的小红书账号不被平台判定为恶意脚本，助手特意加入了**“拟人化慢速节奏”**（每次请求模拟真人停顿 2~4 秒）。慢一点，但永远安全！

**Q：为什么有的评论显示为“二级子回复”？**  
A：小红书默认会把很多互动回复折叠在“展开 7 条回复”里，普通工具抓不到。助手会自动递归帮你展开，并在 Excel 里贴心地标注为 `↳ 二级子回复`。

**Q：导出的 Excel 文件存放在哪里？**  
A：点击导出后，文件会直接下载到你电脑的默认「下载（Downloads）」文件夹中，文件名会自动带上精确到秒的时间戳，绝不会互相覆盖。
