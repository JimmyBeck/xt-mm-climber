# 小天媒媒助手 (xt-mm-climber)

> 新一代安全合规、真实宿主环境的小红书全自动数据采集、素材归档与内容资产治理扩展。

---

## 🌟 核心特性亮点

- **🛡️ 账号安全第一防御体系**：
  - **真实宿主执行**：100% 运行在用户真实 Chrome 浏览器环境中，直接复用当前设备的合法硬件指纹与登录态，零异地/伪造指纹封号风险。
  - **拟人化动态抖动 (Gaussian Jitter)**：单请求严格插入 `2.5s ~ 4.5s` 随机延时，每连续 10 篇自动强制冷却 25 秒。
  - **存活看门狗 (Watchdog 12s)**：请求超时自动熔断切断，保全已有数据并跳过，绝不死机或卡死主流程。
  - **人机协同熔断器 (HITL)**：遭遇 461 滑块验证码立即挂起任务，引导用户真人滑动一次后自动无缝恢复。
- **⚡ 双层评论游标穿透引擎**：
  - 自动遍历一级评论多页游标（`comment/page`）直至官方末页。
  - 自动递归展开并提取单条主评下所有折叠的**“展开 X 条回复”**（`comment/sub/page`），无漏抓。
- **📦 高清素材一键打包**：
  - 自动剔除小红书 CDN 水印与压缩参数，提取未压缩原图。
  - 提取 Master 级高清无水印 MP4 视频流。
  - 一键将单篇笔记所有无水印素材打包为 ZIP 归档。
- **📊 专业排版 Excel 与人话版诊断报告**：
  - 精确到秒级时间戳的 Excel 文件命名（`YYYYMMDD_HHmmss`），多次导出不重名。
  - 任务结束后自动生成诊断报告，清晰讲清 100% 抓取、超时跳过或笔记删除的原因。
- **🖥️ 实时黑客级执行终端 (Live Terminal)**：
  - 抽屉内置毫秒级实时发包流水日志与秒级冷却倒计时监控，任务透明可观测。

## 🚀 快速上手与本地加载

### 1. 安装依赖与构建
```bash
# 安装依赖
npm install

# 编译打包 Chrome MV3 产物
npm run build
```
构建成功后，产物将生成在项目根目录的 `.output/chrome-mv3` 目录下。

### 2. 在浏览器中加载
1. 打开 Chrome / Edge 浏览器，访问 `chrome://extensions/`；
2. 开启右上角的 **「开发者模式」** 开关；
3. 点击左上角的 **「加载已解压的扩展程序」**；
4. 选择当前项目的构建产物目录：`.output/chrome-mv3`。

### 3. 开始使用
1. 打开 [小红书网页版](https://www.xiaohongshu.com/explore)；
2. 页面右侧将出现红色的 **「小天媒媒助手」** 悬浮胶囊挂件；
3. **日常刷帖（场景 A）**：正常浏览，插件自动静默拦截并展示数据；
4. **全自动深度采集（场景 B）**：切换至「🚀 全自动采集」工作台，点击一键提取当前笔记全量评论或输入博主链接批量采集全部笔记。

## 🤝 敏捷开发与协作标准 (Team Collaboration Standards)

本项目采用 **「产品经理 (PO) + 技术负责人 (Tech Lead)」** 的双人敏捷结对开发模式。

### 1. 核心协作准则
* **安全底线高于一切**：任何新增功能或性能优化，必须以“不触发小红书风控、不导致用户封号”为第一准则。
* **简单优先 (KISS / YAGNI)**：只写解决当前问题所需的最少代码，杜绝过度投机性抽象。
* **全链路可观测**：涉及自动化流程的改动，必须接入看门狗超时保护与实时终端日志。
* **数据完全私有化**：坚持 100% 本地运算与存储，严禁向任何第三方服务器上传用户小红书 Token 或采集数据。

### 2. Git 提交信息规范 (Conventional Commits)
* `feat:` 新增功能（如：`feat: 支持博主笔记全量游标采集`）
* `fix:` 修复缺陷（如：`fix: 修复折叠回复递归翻页超时问题`）
* `docs:` 文档变更（如：`docs: 更新白皮书与场景矩阵`）
* `refactor:` 代码重构与性能优化
* `chore:` 构建配置或依赖升级
